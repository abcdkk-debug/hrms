# HRMS 人力資源管理系統

一個可直接喺瀏覽器運行嘅人力資源管理系統（Human Resource Management System）示範版，純 HTML / CSS / JavaScript 單頁應用，無需後端伺服器，資料儲存在瀏覽器 IndexedDB，支援深色模式同中英文介面切換。

🌐 **線上版（GitHub Pages）：** https://abcdkk-debug.github.io/hrms/

## 功能

- **儀表板**：在職人數、部門數、請假中人數、今日出勤率、平均月薪、各部門人數圖、待批核請假、最近入職員工
- **員工管理**：搜尋 / 部門及狀態篩選、新增、編輯、刪除、員工詳情、匯出 CSV；預載 12 位示範員工
- **部門管理**：部門卡片（主管、人數、每月薪金支出）、新增 / 編輯 / 刪除（部門仍有員工時會阻止刪除）
- **考勤管理**：今日打卡記錄、上班 / 下班打卡模擬、09:00 後自動標示遲到
- **請假管理**：年假 / 病假 / 事假 / 婚假 / 產假 / 陪產假申請、批核 / 拒絕（批核年假、病假會自動扣減餘額）、假期餘額一覽
- **薪酬管理**：月薪總額、實發薪金，及按香港強積金（MPF）規則示範計算（僱主及僱員各 5%，每月上限各 HK$1,500；月入低於 HK$7,100 僱員免供款）、匯出薪酬 CSV
- **批量調整薪酬**（2026-11-22 新增）：按全部員工或指定部門，以百分比或固定金額（可負數減薪）一次過調整；套用前有逐人前後對照預覽及每月／全年成本變化，套用後有調整記錄，並可撤銷還原
- **招聘管理**（2026-11-23 新增）：職位空缺列表（職位、部門、聘用形式、空缺數、薪酬範圍、狀態）、應徵者名單及面試階段（已申請／面試中／已出 offer／已聘用／已拒絕），可增刪改、推進階段、拒絕／重新考慮、開關職位；已聘用應徵者可一鍵轉為正式員工（自動按職位部門及薪酬範圍中位數建立員工記錄）；儀表板新增開放職位統計
- **績效評核**（2026-11-24 新增）：評核週期管理（新增／結束／重新開放／刪除，有評核記錄嘅週期唔可以刪除）、每位員工四個維度評分（工作表現、團隊合作、主動性、溝通能力，各 1–5 分）及評語，總分為四項平均分並按 4.5／3.5／2.5 分界評級（優秀／良好／一般／需改善）；同一員工同一週期只可有一項評核（重複會提示改為編輯），已結束週期唔可以新增或修改評核；部門平均分統計、公司平均分、已評核／待評核人數，儀表板新增最新週期平均評核分
- **培訓管理**（2026-11-25 新增）：培訓課程列表（課程、類別、主辦單位、形式、日期、時數、費用、名額及狀態，可增刪改；狀態可由開放報名 → 進行中 → 已完成，完成課程時報名中嘅學員會自動標示完成）、員工報名／完成／取消記錄（重複報名及名額已滿會自動阻止）、培訓時數統計（課程總數、報名人次、已完成總時數、人均時數、部門及員工時數一覽），儀表板新增培訓總時數
- **IndexedDB 儲存**（2026-11-22 新增）：資料改存瀏覽器 IndexedDB（資料庫 `hrms-db`），唔再用 localStorage；舊版 localStorage 資料會喺首次開啟時自動遷移過去
- **深色／淺色模式**（2026-11-22 新增）：側欄一鍵切換，偏好會記低
- **中英文介面**（2026-11-22 新增）：側欄一鍵切換繁體中文／English，全介面（包括狀態、假期類型、提示訊息）同步翻譯，偏好會記低；員工及部門等資料本身保持原文

## 使用方法

直接用瀏覽器打開 `index.html`，或者用 GitHub Pages 線上版。所有新增 / 修改會即時存入 IndexedDB；側欄底部可一鍵「重設示範資料」。

## 技術

- 單一 `index.html`（HTML + CSS + 原生 JavaScript），零依賴、零建置步驟
- 響應式版面，支援手機瀏覽

## 注意

此為前端示範系統，沒有帳戶登入、權限控制及後端資料庫，不適宜直接用於儲存真實員工敏感資料。正式使用應接駁後端 API、身份驗證及加密儲存。
